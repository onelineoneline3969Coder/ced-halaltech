# 🤝 Politique de Contribution (CED HalalTech™)

**Version :** 1.0 | **Date :** Mai 2026 | **Statut :** En vigueur

Bienvenue dans l'écosystème **CED HalalTech™**. Toute contribution externe est soumise à une validation stricte pour garantir notre cohérence éthique, spirituelle et technique.

## 1. Les 3 Piliers Non-Négociables
En contribuant, vous acceptez :
1.  **Souveraineté Numérique :** 100% du code et des données restent en **Suisse** (Infomaniak). Zéro Cloud Act.
2.  **Conformité Charia :** Zéro Riba (intérêt), Zéro Gharar (incertitude), Zéro Haram.
3.  **Propriété Intellectuelle :** Le code reste la propriété exclusive de CED HalalTech™ (Licence Propriétaire).

## 2. Processus de Contribution
Contrairement à l'Open Source classique, **l'accès n'est pas public**.
1.  **Demande :** Remplissez le [Formulaire d'Autorisation](docs/AUTHORIZATION_FORM.md).
2.  **Validation :** Signature d'un NDA et validation par le comité d'éthique.
3.  **Développement :** Utilisation obligatoire des hooks `pre-commit` (voir `YasCoder`).
4.  **Revue :** Triple validation (Technique, Éthique, Sécurité).

## 3. Standards de Code (Wasatiyyah)
*   **Clarté :** Code commenté, variables explicites.
*   **Couleurs :** Chaque fichier doit contenir l'emoji de couleur correspondant à son module (ex: `🟩` pour Finance, `🟦` pour Infra).
*   **Sécurité :** Aucun secret (mot de passe, clé API) ne doit être commité.

## 4. Signalement de Faille
Toute faille de sécurité doit être rapportée à `security@ced-halaltech.ch`. Nous ne poursuivrons pas les chercheurs agissant de bonne foi.

> *"Allah vous ordonne de rendre les dépôts à leurs ayants droit." (Sourate 4:58)*
